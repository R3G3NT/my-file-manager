_**Моя курсовая работа 1 курса по программированию!**_

Самый простой файловый менеджер, в котором можно перемещаться с помощью стрелочек:
_ВВЕРХ/ВНИЗ_: Перемещение между файлами и папками в списке
_ВЛЕВО_: Вернуться назад (на папку, где были до этого)
_ВПРАВО_: Перейти вперед (если вы использовали «назад»)

Помимо этого есть возможность выбирать файлы для лабораторных работ 2 семестра:
**BYTE TABLE:**
F1 - 1 лабораторная работа
Данное приложение отображает таблицу вероятности встречаемости байта в файле. Также есть возможность переключить режим на количественное отображение. 
Для _txt_ файла можно посмотреть круговую диаграмму двух групп, где первая группа символы _a-z, A-Z, 0-9_, другая группа все остальные.

**WAV ENCODER AND DECODER:**
F2 - 2 лабораторная работа
Эта программа позволяет конвертировать любой файл в формат _wav_, а также конвертировать его обратно, сохраняя название и формат исходного файла.
Скачать и изучить её подробнее можно здесь => https://github.com/Approximatio/wav-encoder

**WAV VISUALIZER:**
F3 - 3 лабораторная работа
Данное приложение строит гистограмму частот на каждой секунде _wav_ файла.

**ARITHMETIC CODING:**
F4 - 4 лабораторная работа
Эта программа кодирует и декодирует любой файл (до 8 желательно байт 😁) с помощью арифметического кодирования.

Все ТЗ лабораторных работ можно найти в Project Files (✿◡‿◡)
