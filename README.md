## 📂 Console File Manager & Data Tools
_Курсовая работа за 1 курс по программированию._

Это минималистичный консольный файловый менеджер для Windows с набором встроенных утилит для анализа и обработки данных (лабораторные работы за 2 семестр).

## 🎮 Управление
Интуитивная навигация с помощью стрелок:

* ⬆️ / ⬇️ — Перемещение между файлами и папками в списке.
* ⬅️ — Вернуться на уровень выше (назад).
* ➡️ — Открыть папку.

------------------------------
## 🛠 Лабораторные работы
В программу добавлены четыре утилиты, которые можно вызвать после выбора файла:
## 1. 📊 Byte Table (F1)
Анализ структуры файла.

* Отображение таблицы вероятности встречаемости каждого байта.
* Переключение режима на количественное отображение.
* Для _.txt_ файлов: Построение круговой диаграммы (Символы a-z, A-Z, 0-9 vs Остальные символы).

## 2. 🎵 WAV Encoder & Decoder (F2)
Утилита для маскировки данных под аудио.

* Конвертация любого файла в формат _.wav_.
* Обратное декодирование с сохранением исходного имени и расширения.
* Подробнее: https://github.com/Approximatio/wav-encoder

## 3. 📈 WAV Visualizer (F3)
Визуализация аудио-данных.

* Построение гистограммы частот для каждой секунды выбранного _.wav_ файла.

## 4. 👨‍💻 Arithmetic Coding (F4)
Сжатие данных.

* Кодирование и декодирование файлов методом арифметического кодирования.
* Оптимально работает с небольшими файлами (до 8 байт).

------------------------------

Программа не работает корректно в новом **Windows Terminal**! 

Чтобы она правильно функционировала на Windows 11 выберите приложение терминала "**Узел консоли Windows**".

Подробнее, как это сделать описано здесь: https://remontka.pro/classic-cmd-windows-run/
